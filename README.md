"# Contatos-Basquete" 
Projeto feito com EJS, utilizando as tecnologias HTML, CSS, JavaScript e Node.JS sem banco de dados.
Gerenciar, editar, adicionar e exibir contatos com os campos Nome, Data de Nascimento, E-mail e Posição do jogador.

Para rodar o servidor:
1. Esteja dentro da pasta "site_conteudo";
2. Execute o comando "npm install" para instalar as dependências e a pasta node modules;
3. Dentro da pasta "site_conteudo", execute o comando "node server.js" no CMD ou Terminal Integrado do VS Code;
4. Abra o servidor com "http://localhost:3000".
